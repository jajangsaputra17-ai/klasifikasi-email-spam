Klasifikasi Email Spam dan Ham (NLP)
Tugas Laporan Praktikum Machine Learning - Klasifikasi Email Spam dan Ham.
Proyek ini dibuat untuk memenuhi Tugas Laporan Praktikum Machine Learning.

Deskripsi Proyek
Model klasifikasi untuk membedakan pesan email Spam dan Ham (normal) berbasis Natural Language Processing (NLP) menggunakan metode ekstraksi fitur TF-IDF.

Algoritma yang Digunakan
1. Multinomial Naive Bayes
2. Logistic Regression

File dalam Repositori
- dataset_spam_ham_1600.csv: Dataset berisi 1.600 baris teks email berbahasa Indonesia.
- klasifikasi_spam_ham.ipynb: Jupyter Notebook berisi proses preprocessing, pelatihan model, dan evaluasi.
